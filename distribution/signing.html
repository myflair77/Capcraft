Code signing policy

Updated: 2026-09-21

Current status: unsigned / application preparation

Capcraft is preparing an application to the SignPath Foundation open-source code-signing program. Acceptance and a signing certificate have not been granted. Current Capcraft 1.2 downloads are unsigned. This page does not claim that SignPath endorses or signs these downloads.

현재 배포본은 미서명 상태입니다. SignPath Foundation 무료 오픈소스 서명 지원 신청을 준비하고 있으며, 승인이나 실제 서명은 아직 완료되지 않았습니다.

Project and proposed roles

Capcraft is maintained by JBH (myflair77). Proposed author, reviewer and signing approver: JBH. Enrollment requires maintainer confirmation of roles, MFA and provider requirements.

Build and release controls

The GitHub Actions Windows workflow builds review artifacts from the repository on GitHub-hosted runners. These artifacts are not automatically signed or published as releases. Production signing integration remains pending approval. Each future signing request will require maintainer approval, and signed releases must pass signature and timestamp verification. Third-party libraries will not be re-signed as Capcraft-owned binaries.

Provider attribution after approval only

If accepted, we will publish the required attribution “Free code signing provided by SignPath.io, certificate by SignPath Foundation”. This is a proposed future attribution, not the current signing status. Such certificates identify SignPath Foundation as the certificate publisher.

Privacy

OCR and captures stay on the user's PC. Automatic update checks contact GitHub and can be disabled in application settings. See the privacy notice for network behavior and hosting-provider policies. Installation-time privacy controls remain an enrollment preparation item.
