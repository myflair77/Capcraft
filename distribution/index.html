CAPTURE. EXPLAIN. SHARE.

한 장이면 충분하도록.

01 / CAPTURE

담고, 바로 편집

화면을 캡처하거나 PNG·JPG·WebP를 열어 작업하세요. 최근 목록으로 이미지를 오가며 편집할 수 있습니다.

02 / ANNOTATE

표현은 자유롭게

볼펜, 형광펜, 연필, 붓, 목탄. 도형과 화살표, 점선과 물결선으로 원하는 부분을 강조하세요.

03 / FOCUS

작은 부분도 크게

팝아웃으로 세부를 확대하고 연결선으로 맥락을 보여주세요. 스마트 정렬 가이드로 배치를 맞출 수 있습니다.

04 / LOCAL OCR

이미지에서 텍스트로

한국어·영어·중국어·일본어 등 10개 언어를 지원합니다. PC 내부에서 인식하고, 결과를 복사하거나 문단을 정리하세요.

GET STARTED

설치부터 첫 캡처까지.

현재 배포 대상은 Windows 64비트입니다.
OCR 모델이 포함되어 설치 용량이 클 수 있습니다.

  1. 설치파일 다운로드GitHub Releases의 Assets에서 Capcraft_Setup 파일을 받으세요. Source code 파일은 설치파일이 아닙니다.
  2. 실행 전 게시자 확인서명되지 않은 초기 배포본에는 Windows 경고가 표시될 수 있습니다. 보안 기능을 끄지 말고 다운로드 출처와 해시를 확인하세요.
  3. 설치 후 Capcraft 실행새 캡처 또는 열기로 시작하세요. 환경설정에서 업데이트 알림을 켜거나 직접 확인할 수 있습니다.

새 버전도 놓치지 마세요.

프로그램 실행 후 새 버전을 확인하고, 알림의 버튼을 누르면 다운로드 페이지로 이동합니다.
설치파일 다운로드와 설치는 사용자가 직접 진행합니다.
