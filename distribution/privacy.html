개인정보 처리 안내

작성일: 2026-09-21 · 대상: Capcraft 1.2 및 공식 다운로드 안내 사이트 · 운영: JBH

캡처 이미지와 OCR

캡처 이미지와 OCR 인식은 사용자 PC 내부에서 처리합니다. Capcraft에는 캡처 이미지·OCR 결과를 외부 OCR 서비스나 개발자 서버로 업로드하는 기능이 없습니다. 사용자가 복사·저장한 자료를 다른 서비스에 공유하는 행위는 사용자의 선택입니다.

PC에 저장되는 정보

최근 캡처·편집 기록, 환경설정, 업데이트 확인 설정은 사용자 PC에 저장됩니다. 최근 목록은 앱에서 개별 삭제 또는 모두 삭제할 수 있습니다. 앱 제거만으로 기존 사용자 기록·설정을 자동 삭제하지 않습니다. JSON 작업 파일에는 원본 이미지가 포함될 수 있으므로 공유 전 내용을 확인해 주세요.

업데이트 확인과 외부 접속

자동 업데이트 확인은 기본적으로 켜져 있으며 앱 실행 후 GitHub(raw.githubusercontent.com)의 버전 안내 파일을 요청합니다. 성공한 자동 확인은 하루 한 번으로 제한됩니다. 이미지·OCR 텍스트를 이 요청에 포함하지 않지만, GitHub에는 IP 주소 등 일반적인 HTTP 연결 정보가 전달될 수 있습니다. 환경설정의 ‘실행 시 새 버전 확인’을 해제할 수 있고, ‘지금 업데이트 확인’을 누르면 수동 요청이 발생합니다. 현재 설치 과정에는 이 설정을 해제하는 별도 선택지가 없습니다.

다운로드 버튼을 누르면 외부 브라우저가 열립니다. 공식 안내 사이트는 Vercel, 설치파일과 소스는 GitHub가 제공합니다. 해당 서비스가 접속 로그 등을 처리하는 방식은 각 서비스의 방침을 따릅니다.
