1. 캡처 도구 (Capture Tools)
Capcraft 실행창 (미니 런처) 및 캡처 직후 자동 복사

프로그램을 실행하면 화면을 가리지 않는 작은 가로형 Capcraft 실행창이 먼저 열립니다. 원하는 캡처 방식을 한 번에 클릭해 바로 촬영할 수 있고, 캡처목록을 누르면 편집창으로 전환됩니다.

• 빠른 창 전환: 캡처 중 ESC로 취소하거나 편집창의 닫기(×)를 누르면 기존 작업 내용을 유지한 채 미니 실행창으로 돌아갑니다. 프로그램을 완전히 종료하려면 미니 실행창의 닫기(×) 또는 메뉴 → 종료를 사용하세요. • 단일 인스턴스 실행: 이미 Capcraft가 실행 중일 때 단축 아이콘이나 실행 파일을 다시 실행하면 새 창을 중복으로 띄우지 않고 기존 실행창을 맨 앞으로 불러옵니다. • 캡처 직후 자동 클립보드 복사: 캡처가 완료되면 원본 이미지가 자동으로 클립보드에 복사되므로, 복사 버튼을 누르지 않아도 다른 앱에 바로 Ctrl+V로 붙여넣을 수 있습니다. 도형·텍스트 등을 편집한 이미지를 복사할 때는 상단 복사 버튼을 사용하세요. (환경설정 → 캡처 설정에서 켜기/끄기 가능) • 화면 비율 자동 맞춤: 편집창이 처음 열릴 때 모니터 해상도·배율에 맞춰 상단바와 사이드바 비율이 자동 최적화되며, 새 캡처 이미지는 좌우 폭맞춤 상태로 표시됩니다. 이후 창 크기 조절과 Ctrl+마우스 휠 확대/축소는 자유롭게 사용할 수 있습니다.
새캡처 기능 그룹
✦ 직접지정 마우스 드래그로 원하는 사각형 영역을 커스텀하게 조절하여 캡처합니다.
✦ 창 캡처 마우스를 올린 윈도우 창을 감지해 캡처합니다. 가능한 경우 Windows가 제공하는 실제 표시 테두리를 기준으로 영역을 잡아 창 밖의 보이지 않는 크기 조절 여백이 함께 들어가는 것을 줄입니다. 캡처 전에 강조된 영역이 원하는 창인지 확인하세요.
✦ 단위영역 앱이나 웹 내의 이미지, 버튼, 텍스트 상자 등 감지 가능한 개별 영역을 선택해 캡처합니다. 대상 프로그램이 제공하는 영역 정보에 따라 감지 범위가 다를 수 있으므로 원하는 영역이 잡히지 않으면 직접지정을 사용하세요.
✦ 전체화면 모니터의 화면 전체를 딜레이 없이 즉시 캡처합니다.
✦ 스크롤 캡처 길이가 긴 웹페이지나 문서를 자동으로 스크롤하며 여러 화면을 하나의 긴 이미지로 병합합니다. 고정 메뉴, 움직이는 광고, 지연 로딩이나 대상 앱의 스크롤 방식에 따라 이음새가 달라질 수 있으므로 결과를 확인하세요.
✦ 크기지정 사전에 정의된 폭과 높이 값을 바탕으로 캡처 박스 영역을 고정하여 캡처합니다.
2. 편집 도구 (Editing Tools)
상단 툴바 호버 미리보기 & 옵션 클릭 시 자동 활성화

상단바의 텍스트 · 펜 · 도형 · 이모티콘 · 이미지 · 모자이크 · 지우개 · 자르기 버튼 위에 마우스만 가져다 대도 해당 도구의 옵션 창이 미리 열립니다. 마우스만 올렸을 때는 상단 도구의 활성화 상태가 바뀌지 않으며, 열린 옵션 창 안에서 원하는 옵션을 클릭·변경하면 그 도구가 자동으로 활성화됩니다.

텍스트 도구 (Text)
캔버스의 빈 영역을 마우스로 클릭하여 간편하게 다국어 텍스트를 입력 및 편집합니다.
옵션 상세 • 글자 크기: 직관적인 숫자 조절로 크기를 동적 스케일링 • 글꼴 스타일: B 굵게 / I 기울임 / U 밑줄 지원 • 배경 조절: 글자 색상 뿐 아니라 입력 상자의 반투명도 설정 및 배경 하이라이트 색상 지정 가능
펜 도구 (Pen)
자유로운 브러시 형태의 필기를 하거나, 반투명 자석 기능이 포함된 직선 긋기 도구입니다.
옵션 상세 • 펜 타입: 볼펜, 형광펜, 연필, 붓, 목탄의 다섯 종류를 지원합니다. 볼펜은 또렷한 선, 형광펜은 반투명 강조, 연필은 입자감 있는 가는 필기, 붓은 붓질 느낌, 목탄은 거친 질감 표현에 적합합니다. • 선 모양: 일반 실선뿐 아니라 점선, 물결선, 끝에 화살표가 있는 선을 그릴 수 있습니다. 세 효과는 각각 켜고 끌 수 있으며 점선과 물결선을 동시에 적용할 수도 있습니다. • 자석 줄긋기: 드래그 진행 중 수평 및 수직 정렬을 완벽하게 맞추는 자석형 직선 보정 지원
도형 도구 (Shapes)
캔버스에 완벽한 비율과 크기를 자랑하는 다양한 기본 기하학 도형을 그립니다.
옵션 상세 • 도형 유형: 직사각형, 마름모, 타원, 선분, 화살표를 지원합니다. 도형 종류 드롭다운에 마우스를 올리면 목록이 펼쳐지며, 선택한 종류가 버튼에 계속 표시됩니다. • 선 및 채우기: 선 굵기 조절, 점선 선택 및 도형 내부 채우기 배경색 지원 • 화살표 모양: 삼각형, 스텔스형, 오픈형 헤드와 크기 제어 • 팝아웃 개체 변환: 선택한 도형 영역을 확대해 입체적으로 튀어나온 듯한 '팝아웃' 개체로 만들 수 있습니다. '연결선'이 켜져 있으면 원본과 팝아웃에 연결된 선분도 생성됩니다. 원본이나 팝아웃을 이동하면 연결선이 따라갑니다. 환경설정과 팝아웃 옵션에서 회전, 기울기, 테두리, 그림자, 선명도를 조절할 수 있으며 아래 팝아웃 상세 안내에서 연결선 편집 방법도 확인할 수 있습니다.
이모티콘 도구 (Emoticon)
풍성한 감정을 표현하는 이모티콘을 캔버스에 자유롭게 삽입합니다.
옵션 상세 • 다양한 이모티콘 제공: 내장된 다양한 이모티콘을 클릭 한 번으로 손쉽게 삽입할 수 있습니다. • 사용자 지정 이모티콘: 내 PC의 로컬 폴더를 커스텀 이모티콘 탭에 연결하여, 자신만의 이미지(PNG, JPG, SVG 등)를 이모티콘 패널에서 즉시 불러와 캔버스에 자유롭게 배치할 수 있습니다. 연결된 경로는 자동으로 저장되어 다음 실행 시에도 유지됩니다.
이미지 도구 (Image)
로컬에 저장된 이미지나 스크롤 캡처 결과를 현재의 작업 화면 위에 얹어 결합시킵니다.
전용 스마트 자르기 • 다양한 프레임: 원본 삽입 기능 외에도 가져온 사진을 원형, 타원형, 사각형 프레임 모양으로 깔끔하게 가공하여 크롭 삽입할 수 있습니다.
모자이크 도구 (Mosaic)
선택한 영역을 가우시안 블러로 부드럽게 흐리게 만듭니다. 현재 이름은 '모자이크'이지만 사각 픽셀을 뒤섞는 방식이 아니라 뿌옇게 흐려지는 효과입니다. 민감한 정보를 완전히 삭제하는 기능은 아니므로 공개할 자료는 별도로 확인해야 합니다.
옵션 상세 • 다양한 모양 지원: 기본 '직사각형' 외에도 '타원' 모양을 지원하며, 펜처럼 자유롭게 칠할 수 있는 '자유선' 모자이크 기능이 추가되었습니다. • 자유선 곡선 자동 보정: '자유선' 모자이크를 그릴 때 마우스를 떼지 않고 0.5초간 멈춰있으면, 손떨림이 제거되고 매끄럽고 부드러운 곡선 형태로 마스킹 영역이 자동 보정되는 스마트 기능을 지원합니다. • 환경설정 연동 및 강도 조절: 환경설정의 '모자이크 설정'에서 모자이크 강도와 자유선 굵기의 기본값을 지정하고 저장할 수 있습니다. 모자이크 강도 기본값은 5이며 상단 옵션에서는 1~20 범위로 지정합니다. 높은 값일수록 더 흐려집니다. 이미 만든 결과를 다시 만들 때는 이전 모자이크를 지우고 원하는 강도로 새로 그려 확인하세요.
자르기 도구 (Crop Canvas)
전체 캔버스 영역 중 필요한 핵심 부분만 선별하여 전체 크기를 축소하거나, 필요에 따라 캔버스 영역을 더 넓게 확장할 수도 있습니다.
캔버스 재정의 • 가변 컨트롤러: 선택 도우미 테두리의 핸들을 조절하여 원하는 중심 영역을 선정한 뒤 적용을 누르면 캔버스가 깔끔히 정제됩니다. 테두리의 핸들을 캔버스 바깥으로 드래그하여 적용하면 캔버스의 영역이 확장됩니다.
3. 시스템 및 파일 (System & File)
저장 옵션 (Save Options)
✓ PNG / JPG / SVG PNG는 투명 배경을 지원하는 무손실 이미지 형식입니다. JPG는 사진 공유에 적합한 압축 이미지이며 투명 영역은 흰색으로 처리되고 압축에 따른 화질 손실이 생길 수 있습니다. SVG는 도형과 텍스트의 벡터 표현을 유지할 수 있지만, 원본 캡처·삽입 사진·모자이크·팝아웃 같은 비트맵 요소가 자동으로 벡터로 바뀌지는 않습니다.
✓ PDF 내보내기 캔버스의 모든 작업 내역을 단일 레이아웃 문서 형식으로 변환합니다.
✓ JSON 프로젝트 그린 벡터 개체, 텍스트 속성을 모두 담은 고유 포맷으로 저장하여 추후 더블클릭이나 이동 등 레이아웃 재작업을 자유롭게 할 수 있습니다.
프로젝트 열기 & 클립보드 복사
✓ 열기 (Open) PNG, JPG, JPEG, WebP 이미지를 새 작업의 배경으로 불러오거나, 이전에 저장한 JSON 프로젝트를 열어 개체 편집을 이어갑니다. 일반 이미지에 이미 합쳐진 글자나 도형은 개별 개체로 분리되지 않습니다. 편집 가능한 상태를 보관하려면 JSON도 함께 저장하세요.
✓ 클립보드 복사 렌더링 결과를 메모리 클립보드에 스냅 복사하여 곧바로 카카오톡, 메일 등에 간편히 붙여넣기 하실 수 있습니다.
4. 조작 팁 & 핵심 노하우
• 개체 더블클릭: 캔버스 내 삽입된 텍스트, 선, 도형 등을 더블 클릭하면 각 유형에 최적화된 개체 속성 수정 창이 나타나 실시간 편집이 가능합니다.
• 반전 및 조작: 개체를 선택하면 나타나는 조작 아이콘과 핸들을 통해 회전, 크기 조절, 좌우/상하 제자리 반전을 할 수 있습니다. 선분과 화살표는 끝점 핸들을 이용해 시점과 종점을 따로 조절합니다.
• 다중 제어 (Ctrl / Shift): Ctrl 키를 누르고 빈 곳에서 드래그하면 영역으로 여러 개체를 선택할 수 있습니다. Shift를 이용한 다중 선택도 지원합니다. 선택된 개체들을 한 번에 이동하거나 삭제할 수 있으며, 연결된 선분과 대상 개체를 함께 선택해 이동하면 그 사이의 연결이 유지됩니다.
• 화면 탐색 (Panning): 편집 도구가 활성화되지 않은 대기 상태에서는 빈 공간을 마우스로 드래그하면 캔버스 전체가 부드럽게 패닝 이동합니다.

스크롤 캡처 활용 꿀팁
스크롤 캡처 진행 시 [Delete] 키 또는 화면 하단에 나타나는 [여기까지만 캡처] 버튼을 누르시면, 굳이 끝까지 기다리지 않더라도 현재 진행 중인 부분까지만 부드럽게 잘라서 캡처를 신속하게 마칠 수 있습니다.
5. 펜·도형의 상세 사용법과 연결 편집
펜 종류 선택과 옵션 변경

상단의 '펜'을 누른 다음 옵션 창 왼쪽의 펜 종류에 마우스를 올리세요. 클릭하기 전에도 목록이 펼쳐집니다. 볼펜·형광펜·연필·붓·목탄 중 원하는 항목을 선택하면 목록이 닫히고 현재 종류가 표시됩니다. '도형'의 도형 종류와 펜 종류도 같은 방식으로 선택합니다. 두 도구의 옵션은 한 줄로 배치되어 있습니다.

• 새로 그릴 때: 펜 종류를 선택하면 환경설정에 저장한 해당 종류의 선 굵기와 색상 등 기본 속성이 적용됩니다. 도형에서도 펜 종류를 변경하면 해당 펜의 설정을 가져옵니다. 도형의 기본 펜 종류는 볼펜입니다. • 선과 배경 구분: '선 색상'은 필기나 외곽선의 색이고 '배경 색상'은 채움 색입니다. 배경 투명도 100은 완전히 투명하고, 0은 불투명합니다. 선의 농도와 배경 투명도는 서로 다른 설정입니다. • 질감과 농도: 연필과 목탄은 작은 입자와 빈틈을 포함한 질감으로 표현됩니다. 농도를 높이면 더 진해지지만 볼펜처럼 균일한 면으로 바뀌지는 않습니다. 연필·붓·목탄의 농도는 환경설정에서 각 종류별로 조절합니다. • 그린 뒤 수정: 펜 개체를 클릭해 선택한 후 옵션에서 점선·물결선·화살표를 체크하거나 해제하면 선택한 개체에 반영됩니다. 선 굵기를 바꾸면 점선 간격과 화살표 표현도 갱신됩니다. 효과를 끄면 원래의 중심 경로를 바탕으로 다시 표시하므로 새로 그릴 필요가 없습니다.
점선 · 물결선 · 화살표 조합

펜 옵션의 순서는 '점선 → 물결선 → 화살표'입니다. 각각 독립된 효과이므로 원하는 조합을 선택하세요. 예를 들어 점선과 물결선을 함께 켜면 물결 경로를 따라 끊어진 선이 나타나고, 화살표까지 켜면 종점에 화살표 끝이 붙습니다. 도형의 외곽선에도 점선과 물결선을 함께 사용할 수 있습니다.

• 점선 빈도: 환경설정 → 펜 설정 아래쪽에서 낮음·중간·높음 중 선택합니다. 낮음은 선 조각과 간격이 길어지고, 높음은 짧아져 더 자주 끊어집니다. 실제 간격은 선 굵기에도 영향을 받습니다. • 물결 높이: 중심선에서 얼마나 크게 출렁일지 정합니다. 값이 커지면 물결의 폭이 커집니다. • 물결 간격: 물결이 반복되는 길이를 정합니다. 기본값은 40입니다. 간격을 줄이면 촘촘한 물결, 늘리면 넓고 완만한 물결이 됩니다. • 펜 화살표: 새로 그리는 화살표 끝 모양과 크기는 환경설정 → 도형 설정의 화살표 설정을 따릅니다. 연필·목탄으로 그리면 화살표 끝에도 같은 종류의 질감을 적용합니다. • 일반과 줄긋기: '일반'은 자유롭게 그릴 때 사용하고, '줄긋기'는 반듯한 선을 만들 때 사용합니다. 일반 필기에서 마우스를 누른 채 잠시 멈추면 곡선 보정이 적용되는 동작도 활용할 수 있습니다. 화살표가 있는 필기는 끝부분의 진행 방향이 잘 드러나도록 그리면 좋습니다.
선분·화살표의 경로와 연결점

도형에서 '선분' 또는 '화살표'를 선택하고 일반·꺾은 선·곡선 중 원하는 경로 방식을 사용합니다. 생성된 선을 선택하면 경로를 조절할 수 있는 핸들이 나타납니다. 펜으로 자유롭게 그린 화살표와 도형 도구의 화살표는 편집 방식이 다릅니다. 다른 개체와 연결되는 선이 필요하다면 도형의 선분·화살표를 사용하세요.

• 개체에 연결: 선의 시점 또는 종점을 다른 개체에 연결할 수 있습니다. 연결된 대상이 움직이면 끝점도 함께 이동합니다. • 연결 위치 유지: 한번 정한 연결점은 대상 개체 기준으로 유지됩니다. 개체가 이동할 때 가까운 변이나 반대쪽으로 자동 이동하지 않습니다. 연결 위치를 바꾸려면 사용자가 끝점 핸들을 직접 옮기세요. • 여러 개체와 함께 이동: 연결된 대상과 선을 함께 다중 선택해 이동하면 내부 연결을 유지합니다. 선만 옮기거나 선택되지 않은 대상과 떨어뜨리는 경우에는 연결이 해제될 수 있으므로 이동 뒤 끝점을 확인하세요. • 화살표 속성: 화살표를 더블클릭해 '개체 속성 수정'을 열면 아래쪽에서 끝 모양을 삼각형·스텔스·오픈으로, 끝 크기를 아주 작게·작게·보통·크게·아주 크게로 지정할 수 있습니다. • 방향 전환: 화살표 속성의 '방향 전환'은 시점과 종점을 교환합니다. 기존 시점에 화살표 끝이 생기고 기존 종점의 화살표 끝은 없어집니다. 단순한 좌우 반전과는 다른 기능입니다.
6. 팝아웃으로 확대 강조하기
원본 영역과 확대 개체를 함께 보여주기

작은 글자나 특정 그림 부분을 크게 강조하고 싶을 때 사용합니다. 강조할 영역의 도형을 선택하고 팝아웃 기능으로 확대 개체를 만드세요. 원래 영역과 확대 개체를 서로 떨어뜨려 배치하면 어디를 확대한 것인지 쉽게 설명할 수 있습니다. 팝아웃은 별도 개체이므로 이동·크기 조절·회전이 가능합니다.

• 테두리: 상단 팝아웃 옵션의 '테두리 두께'와 테두리색으로 외곽선을 지정합니다. 기본 두께는 4입니다. 환경설정 → 팝 아웃 설정에서 새 개체에 사용할 기본값을 지정할 수 있습니다. • 입체감: 가로축·세로축 기울기와 그림자색·그림자 강도를 조절합니다. 평면 회전과 축 기울기는 서로 다른 표현이며, 각도를 바꿀 때 외곽선과 선택 영역도 현재 표시 크기를 기준으로 갱신됩니다. • 크기 조절: 꼭짓점 핸들을 잡아 확대하거나 축소합니다. 반대쪽 꼭짓점을 기준으로 크기를 바꾸며, 확대가 끝나면 필요한 표시 품질로 갱신됩니다. • 선명도: 0~100 범위에서 조절하고 기본값은 35입니다. 0은 선명화 후처리를 끕니다. 원본을 변경하지 않고 경계의 대비를 보정하는 기능이므로 원본에 없던 글자나 세부 정보까지 복원하는 기능은 아닙니다. 과도하게 높이면 테두리가 거칠게 느껴질 수 있습니다. • 원본의 한계: 작은 캡처를 아주 크게 확대하면 픽셀이 보일 수 있습니다. 글자가 중요한 자료는 가능한 한 원본 앱에서 크게 표시한 뒤 다시 캡처하세요. 이전에 저장된 저해상도 팝아웃은 새로 생성하는 편이 나을 수 있습니다.
연결선은 독립적으로 편집하는 선분입니다

팝아웃의 연결선은 원본과 확대 개체 양쪽에 연결된 일반 선분입니다. 팝아웃 그림에 합쳐진 장식이 아니므로 연결선만 클릭해 선택하거나 이동·삭제할 수 있습니다. 원본과 팝아웃을 이동하면 연결된 끝점이 함께 따라갑니다.

• 생성할 때 '연결선'이 체크되어 있으면 선분도 함께 만듭니다. 체크를 해제한 상태에서 만든 팝아웃도 나중에 선택해 '연결선'을 켜면 연결선을 만들 수 있습니다. • 연결선의 색상과 두께는 팝아웃 옵션에서 지정합니다. 선분 자체를 선택해 경로나 끝점을 조절하는 것도 가능합니다. • 연결선만 필요 없으면 그 선을 선택해 삭제하세요. 팝아웃 개체 자체를 삭제하는 것과 구분해서 조작해야 합니다.
7. OCR: 이미지에서 텍스트 추출하기
썸네일에서 인식하고 별도 창에서 복사

우측 최근 목록의 각 썸네일 왼쪽 아래에 'OCR' 버튼이 있습니다. 회색 버튼은 아직 인식 결과가 없다는 뜻이며, 클릭하면 인식을 시작합니다. 처리 중에는 '인식 중…'으로 표시되고 중복 실행이 제한됩니다. 완료되면 파란 OCR 버튼으로 바뀌며, 다시 클릭하면 텍스트 결과 창이 열립니다.

• PC 내부 처리: OCR은 로컬 모델로 실행하며 인식할 이미지를 외부 OCR 서비스에 전송하지 않습니다. Python으로 실행한 Capcraft와 필요한 OCR 구성 요소·모델이 준비된 환경에서 사용합니다. 웹 페이지 파일만 따로 열면 OCR을 실행할 수 없습니다. • 이동 가능한 결과 창: 제목 표시줄을 잡아 원하는 곳으로 옮길 수 있습니다. Capcraft 창 밖이나 다른 모니터로 옮겨 원본과 나란히 비교할 수 있으며, 창 크기도 조절할 수 있습니다. • 텍스트 복사: '텍스트를 복사' 버튼은 현재 표시된 내용을 복사합니다. 필요한 구간만 마우스로 선택한 뒤 Ctrl+C로 복사해도 됩니다. '닫기'는 결과 창을 닫는 동작이며 최근 목록의 이미지를 삭제하지 않습니다. • 결과 재사용: 같은 원본의 인식 결과가 있으면 다시 OCR 버튼을 눌러 바로 확인할 수 있습니다. 다른 언어로 시도하거나 결과를 새로 얻으려면 결과 창에서 언어를 선택하고 '다시 인식'을 누르세요.
자동 판별 · 10개 언어 · 한자 혼용

최근 목록 위의 OCR 언어 선택에서 '자동 판별 (10개 언어·한자)'을 기본으로 사용할 수 있습니다. 한국어, 영어, 스페인어, 독일어, 프랑스어, 이탈리아어, 러시아어, 중국어, 일본어, 태국어를 지원하며 한자 전용 선택도 제공합니다. 한국어 문장 속 한자처럼 서로 다른 문자 체계가 한 줄에 섞인 경우도 보완 인식을 시도합니다.

• 혼용 문장: 여러 모델의 인식 결과와 위치를 비교하여 특정 언어가 누락되거나 다른 문자로 읽히는 부분을 보완합니다. 단순히 한 줄 전체를 하나의 언어라고 가정하지 않지만, 모든 문자 조합을 완벽하게 구분하는 것은 아닙니다. • 언어 직접 지정: 문서의 언어를 알고 있고 자동 결과가 좋지 않으면 해당 언어를 선택해 다시 인식해 보세요. 아주 짧은 단어나 숫자만 있는 줄은 언어 판별이 불확실할 수 있습니다. • 중국어·일본어와 한자: CJK 인식 모델을 사용합니다. 비슷한 모양의 글자나 작은 한자는 잘못 읽힐 수 있으므로 사람 이름·기관명·인용문은 원본과 대조하세요. • 확인 안내: 결과 창에 확신도가 낮은 영역이나 확인이 필요한 영역이 표시되면 원본과 비교하세요. 자동 판별은 여러 모델을 사용하므로 단일 언어 지정이나 짧은 이미지보다 시간이 더 걸릴 수 있습니다.
'문단 정리'와 '원문 그대로'

결과 창은 '문단 정리'를 기본으로 보여줍니다. 정리 중에는 원문이 먼저 보일 수 있고 처리가 끝나면 정리된 결과로 바뀝니다. 이미지의 화면 폭 때문에 한 문장 중간에서 끊긴 줄을 연결하고, 문단 간격과 문장 부호 주변의 띄어쓰기를 보정합니다.

• 줄바꿈을 모두 없애는 방식이 아닙니다. 문단 경계와 문자 종류 등을 참고해 연결 여부를 판단합니다. 영어 단어 사이에 공백이 필요한 경우와 한 단어 중간이 끊긴 경우는 다르게 처리하려고 시도합니다. • '원문 그대로'는 OCR이 인식한 줄과 텍스트를 확인하는 모드입니다. 이미지 자체가 아니라 인식 결과이므로 오인식까지 사라지는 것은 아닙니다. • 표, 목록, 코드, 주소, 제품 번호처럼 공백이나 줄바꿈 자체가 의미를 가지는 자료는 '원문 그대로'와 비교한 뒤 복사하세요. 문단 정리가 의미를 이해해 모든 문장을 다시 작성하거나 번역하는 기능은 아닙니다.
중요: OCR은 편집 전 원본 이미지를 읽습니다
캔버스에 나중에 붙인 텍스트·도형·삽입 이미지 등을 합성한 화면을 읽는 것이 아닙니다. 모자이크로 흐린 글자도 원본에 남아 있으면 OCR 결과에 나타날 수 있습니다. 원본 배경 이미지가 없는 빈 캔버스에서는 OCR을 실행할 수 없습니다. 개인정보가 포함된 자료를 공유할 때는 OCR 텍스트와 JSON 프로젝트에 원본 정보가 남을 수 있다는 점을 반드시 확인하세요.
8. 최근 목록·새 배경·이미지 파일 관리
우측 사이드바의 최근 목록

썸네일을 클릭하면 해당 캡처의 배경과 편집 개체가 캔버스에 표시됩니다. 여러 캡처를 번갈아 편집할 때 사용하세요. '최신순/과거순' 버튼으로 표시 순서를 전환할 수 있습니다. 목록은 작업을 전환하기 위한 공간이며 중요한 결과물을 별도 파일로 저장하는 습관이 좋습니다.

• 개별 삭제: 썸네일 오른쪽 위 X 버튼으로 해당 항목을 삭제합니다. 목록에서 제거하는 동작이지 이미 따로 저장한 PNG·JSON 파일을 디스크에서 지우는 동작은 아닙니다. • 모두 삭제: 정렬 버튼 오른쪽의 '모두 삭제'를 누르면 '모두 삭제하시겠습니까?'를 다시 묻습니다. '취소'는 유지, '확인'은 최근 목록 전체와 현재 캔버스·실행 취소 기록을 비우는 동작입니다. 필요한 작업은 먼저 저장하세요. 이 작업을 일반 실행 취소로 되돌릴 수 있다고 생각하면 안 됩니다. • 보관 개수: 환경설정에서 최근 목록 최대 개수를 정할 수 있습니다. 오래 보관해야 하는 작업은 목록에만 의존하지 말고 JSON 프로젝트나 이미지 파일로 저장하세요. • 새 배경 이미지: '+ 새 배경 이미지'를 누르고 크기와 배경색을 지정하면 캡처 없이 빈 작업을 시작할 수 있습니다. 설명 도식이나 안내 이미지를 만드는 데 활용하세요.
'열기'와 '이미지' 도구는 용도가 다릅니다

'열기'는 파일을 새 작업의 배경으로 불러오거나 JSON 작업을 복원합니다. '이미지' 도구는 현재 작업 위에 사진을 편집 가능한 별도 이미지 개체로 얹습니다. 기존 캡처 위에 참고 사진을 붙이려면 '이미지', 사진 자체에 주석을 달기 시작하려면 '열기'를 선택하세요.

• 일반 이미지 열기: PNG·JPG·JPEG·WebP를 지원하며 대문자 확장자도 사용할 수 있습니다. 원본 픽셀 크기를 유지하고, 이미지 준비가 끝난 뒤 화면을 교체합니다. 읽기나 이미지 해석에 실패하면 오류를 안내하고 기존 작업을 유지합니다. • 크기 제한: 안정적인 편집을 위해 파일 크기 64MB 이하, 전체 3,200만 화소 이하, 한 변 16,384px 이하의 이미지를 사용하세요. 제한을 넘으면 안내하며 임의로 원본을 축소하지 않습니다. 파일이 작아도 압축을 풀었을 때 픽셀 수가 클 수 있습니다. • 투명 이미지: 투명도를 가진 PNG·WebP는 투명 영역을 유지합니다. JPG 파일에는 투명도가 없습니다. 사진을 열었다고 사진 안의 글자나 선이 자동으로 텍스트·도형 개체가 되지는 않습니다. • 이미지 삽입: '파일 선택'이나 제공되는 최근 이미지에서 원본을 선택하고, 필요하면 '영역 선택'으로 삽입 범위를 다시 정합니다. 직사각형·정사각형·원·타원 프레임을 사용할 수 있으며 '원본 삽입'과 '선택영역 삽입'을 구분하세요. 준비 후 캔버스를 드래그해 배치합니다. • 사용자 이모티콘: 기존 내장 이모티콘 외에 로컬 폴더를 연결하는 기능을 활용할 수 있습니다. 폴더 연결은 최대 5개까지 지원합니다. 사용자가 가져온 이미지의 배포·사용 권한은 별도로 확인하세요.
9. 저장·복사·인쇄를 상황에 맞게 선택하기
편집용 파일과 전달용 파일을 함께 보관하세요

수정 가능한 원본 작업은 JSON으로, 다른 사람에게 바로 보여줄 결과는 PNG·JPG·PDF 등으로 저장하면 편리합니다. 일반 이미지로 저장한 뒤 다시 열면 여러 개체가 한 장에 합쳐져 있으므로 원래의 개체별 이동이나 속성 수정은 할 수 없습니다. JSON 프로젝트는 신뢰할 수 있는 파일만 여세요.

• 기본 저장 형식: 환경설정에서 자주 쓰는 형식을 지정할 수 있습니다. 자동 저장을 사용할 때는 저장 폴더도 지정하고 실제로 원하는 위치에 파일이 생겼는지 확인하세요. • 클립보드 복사: 캡처 완료 시 원본 이미지가 클립보드에 자동 복사되며(환경설정에서 켜기/끄기 가능), 도형·텍스트 등 편집을 마친 결과를 복사하려면 상단의 복사 버튼을 누르세요. OCR 창의 '텍스트를 복사'와 달리 글자를 편집 가능한 문자열로 복사하는 기능은 아닙니다. • 모자이크와 공개 자료: 블러는 민감 정보의 안전한 삭제를 보장하지 않습니다. 공개용 결과의 가독성을 확인하고, 원본과 개체 정보를 담는 JSON을 민감 정보 제거본으로 공유하지 마세요. 특히 작은 숫자·얼굴·식별 정보는 별도 확인이 필요합니다.
새 인쇄 미리보기 사용 순서

상단 '인쇄'를 누르면 Capcraft 스타일의 미리보기 창이 열립니다. 왼쪽에서 용지를 설정하고 오른쪽에서 결과를 확인한 다음, 하단의 '인쇄…'로 프린터 선택을 진행합니다. 미리보기에서 설정을 조절하는 것만으로 실제 인쇄가 시작되지는 않습니다.

1. 용지 크기: A4·A3·Letter 중 선택합니다. 사용할 프린터가 해당 용지를 지원하는지 확인하세요. 2. 용지 방향: 세로·가로를 선택합니다. 가로로 긴 캡처는 가로 용지를 선택하면 더 크게 배치할 수 있습니다. 3. 미리보기: + / - 버튼으로 보기 배율을 바꾸고 '페이지 맞춤'으로 전체 용지를 확인합니다. 미리보기 확대는 종이에 인쇄되는 이미지 크기를 별도로 늘리는 설정이 아닙니다. 4. 배치: 이미지 비율을 유지해 인쇄 가능 영역 안에 맞추고 가운데 배치합니다. 프린터의 인쇄 불가능 여백은 남을 수 있습니다. 긴 스크롤 캡처도 한 페이지에 맞추므로 글자가 너무 작아지면 필요한 범위로 잘라 인쇄하세요. 5. 인쇄 실행: '인쇄…'를 누르면 시스템 인쇄 창에서 프린터·매수 등을 정합니다. 이 단계에서 용지 설정을 다시 바꾸면 처음 미리보기와 결과가 달라질 수 있습니다. 취소하면 미리보기로 돌아오고, 하단 '닫기'는 인쇄 없이 창을 닫습니다.
10. 환경설정과 자주 쓰는 작업 요령
도구별 기본값을 한 번에 준비하기

우측 사이드바의 '환경설정'에서는 테마, 캡처 크기·품질, 도구별 기본 속성, 핀, 저장 및 최근 목록 관련 옵션을 설정합니다. 선택한 개체를 수정하는 상단 옵션과 앞으로 사용할 기본값을 정하는 환경설정은 용도를 구분하세요. 설정을 바꿨다고 이미 저장된 모든 개체가 일괄 변경되는 것은 아닙니다.

• 펜 설정: 볼펜의 선 굵기·색상, 형광펜·연필·붓·목탄 각각의 선 굵기·색상·농도를 지정합니다. 공통 배경색·배경 투명도와 점선 빈도·물결 높이·물결 간격도 여기서 설정합니다. • 도형 설정: 선과 배경 기본 속성, 화살표 끝 모양과 크기를 설정합니다. 새 펜 화살표의 끝 모양도 이 설정을 참고합니다. • 팝 아웃 설정: 연결선 속성, 기본 회전과 축 기울기, 테두리, 그림자, 선명도를 정합니다. 테두리 두께 기본값은 4입니다. • 모자이크 설정: 강도 기본값은 5이며 자유선 굵기도 따로 지정할 수 있습니다. 직사각형·타원을 드래그하는 동안에는 가이드 영역이 표시되므로 범위를 확인하고 마우스를 놓으세요. • 핀 고정: 도구의 핀을 켜면 한 번 그린 뒤에도 같은 도구를 계속 사용할 수 있습니다. 핀이 꺼져 있으면 삽입 후 선택·편집 상태로 돌아갑니다. 모자이크 옵션의 직사각형·타원·자유선을 누르면 모자이크 도구가 다시 활성화됩니다.
스마트 정렬 가이드선

개체를 드래그하면 다른 개체의 위·아래·왼쪽·오른쪽 가장자리와 가로·세로 중심, 캔버스의 가장자리·중심에 가까워질 때 분홍색 가이드선이 나타나며 자석처럼 정렬됩니다. 회전한 개체는 화면상의 외곽 범위를 기준으로 하고, 다중 선택은 전체 묶음을 기준으로 정렬합니다. 마우스를 놓으면 가이드선은 사라지며 저장·복사·인쇄에는 포함되지 않습니다.

상단 툴바의 자석 버튼(또는 단축키 Alt + G)을 눌러 작업 중에도 원클릭으로 자석 정렬을 켜고 끌 수 있습니다(환경설정과 자동 동기화). 자석이 켜진 상태에서 Alt를 누른 채 이동하면 일시 해제됩니다. 환경설정의 '스마트 정렬'에서 자석 감도를 2~12px로 조절할 수 있습니다(기본 6px, 화면상 거리 기준). 선분·화살표의 끝점 핸들은 기존 연결 기능을 사용하며 정렬 자석과 별도로 동작합니다.

선택·이동·삭제와 화면 탐색
• 개체와 화면 이동 구분: 개체를 잡고 드래그하면 그 개체가 움직입니다. 도구가 꺼진 상태에서 빈 곳을 드래그하면 화면을 이동합니다. 여러 개체를 영역으로 선택할 때는 Ctrl을 누른 채 드래그하세요. • 정밀 이동: 선택한 개체는 방향키로 조금씩 이동할 수 있고 Shift+방향키는 더 큰 간격으로 이동합니다. 글자를 입력 중이거나 설정 입력칸에 커서가 있을 때는 해당 입력 작업이 우선합니다. • 확대·축소: Ctrl을 누른 채 마우스 휠을 돌려 화면 배율을 조절합니다. 화면 확대는 이미지 원본의 픽셀 수를 늘리는 기능이 아닙니다. 상단 옵션 창이 열려 있어도 작업 영역과 구분되도록 여백이 확보됩니다. • 복사·잘라내기·붙여넣기: 선택 개체는 Ctrl+C, Ctrl+X, Ctrl+V로 작업 내에서 복제하거나 옮길 수 있습니다. 이는 상단의 이미지 클립보드 복사와 다른 개체 편집 동작입니다. • 개체 삭제: 선택한 개체는 Delete 또는 Backspace로 삭제할 수 있습니다. '지우개' 옵션의 '개체 모두 지우기'는 현재 작업의 개체를 지우는 기능이며, 사이드바의 최근 캡처 '모두 삭제'와 다릅니다. • 실행 취소·다시 실행: 편집 중 실수했다면 상단의 실행 취소·다시 실행 버튼을 이용하세요. 최근 목록 전체 삭제나 별도 파일 저장까지 모두 되돌리는 기능은 아니므로 중요한 단계는 JSON으로 보관하세요. • 캔버스 확장: 자르기 도구의 영역을 바깥으로 늘려 공간을 추가할 수 있습니다. 확장 배경색은 자동 지정 또는 직접 선택을 사용하고, 범위를 정한 뒤 '확인'을 누릅니다.
