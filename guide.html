오류 신고 및 개선 제안: myflair@naver.com

1. 캡처 도구 (Capture Tools)
새캡처 기능 그룹
✦ 직접지정 마우스 드래그로 원하는 사각형 영역을 커스텀하게 조절하여 캡처합니다.
✦ 창 캡처 마우스를 올려 활성화된 특정 윈도우 창 전체를 자동 감지해 캡처합니다.
✦ 단위영역 앱이나 웹 내의 개별 이미지, 버튼, 텍스트 상자 등을 완벽히 스냅해 자동 캡처합니다.
✦ 전체화면 모니터의 화면 전체를 딜레이 없이 즉시 캡처합니다.
✦ 스크롤 캡처 길이가 긴 웹페이지나 문서를 자동으로 스크롤하며 흔적 없이 하나의 스티칭 이미지로 병합합니다.
✦ 크기지정 사전에 정의된 폭과 높이 값을 바탕으로 캡처 박스 영역을 고정하여 캡처합니다.
2. 편집 도구 (Editing Tools)
텍스트 도구 (Text)
캔버스의 빈 영역을 마우스로 클릭하여 간편하게 다국어 텍스트를 입력 및 편집합니다.
옵션 상세 • 글자 크기: 직관적인 숫자 조절로 크기를 동적 스케일링 • 글꼴 스타일: B 굵게 / I 기울임 / U 밑줄 지원 • 배경 조절: 글자 색상 뿐 아니라 입력 상자의 반투명도 설정 및 배경 하이라이트 색상 지정 가능
펜 도구 (Pen)
자유로운 브러시 형태의 필기를 하거나, 반투명 자석 기능이 포함된 직선 긋기 도구입니다.
옵션 상세 • 펜 타입: 뚜렷하고 얇은 볼펜과 강조용 반투명 형광펜 지원 • 선 모양: 일반 실선 외에도 수려한 점선 그리기 가능 • 자석 줄긋기: 드래그 진행 중 수평 및 수직 정렬을 완벽하게 맞추는 자석형 직선 보정 지원
도형 도구 (Shapes)
캔버스에 완벽한 비율과 크기를 자랑하는 다양한 기본 기하학 도형을 그립니다.
옵션 상세 • 도형 유형: 직사각형, 타원, 일반 직선, 세련된 화살표 • 선 및 채우기: 선 굵기 조절, 점선 선택 및 도형 내부 채우기 배경색 지원 • 화살표 모양: 삼각형, 스텔스형, 오픈형 헤드와 크기 제어
이미지 삽입 (Insert Image)
로컬에 저장된 이미지나 스크롤 캡처 결과를 현재의 작업 화면 위에 얹어 결합시킵니다.
전용 스마트 자르기 • 다양한 프레임: 원본 삽입 기능 외에도 가져온 사진을 원형, 타원형, 사각형 프레임 모양으로 깔끔하게 가공하여 크롭 삽입할 수 있습니다.
모자이크 도구 (Mosaic)
개인정보나 민감한 영역을 간편하게 드래그하여 감각적인 픽셀 조각으로 가려줍니다.
강도 조절 • 정밀 수치 조정: 최소 1부터 20단계 크기 조정을 통해 픽셀 크기를 자연스럽고 조화롭게 변환합니다.
자르기 도구 (Crop Canvas)
전체 캔버스 영역 중 필요한 핵심 부분만 선별하여 전체 크기를 변경합니다.
캔버스 재정의 • 가변 컨트롤러: 선택 도우미 테두리의 핸들을 조절하여 원하는 중심 영역을 선정한 뒤 적용을 누르면 캔버스가 깔끔히 정제됩니다.
3. 시스템 및 파일 (System & File)
저장 옵션 (Save Options)
✓ PNG / JPG 화질 저하 없이 원본 투명 배경 및 고해상도 그래픽 파일로 내보냅니다.
✓ PDF 내보내기 캔버스의 모든 작업 내역을 단일 레이아웃 문서 형식으로 변환합니다.
✓ JSON 프로젝트 그린 벡터 개체, 텍스트 속성을 모두 담은 고유 포맷으로 저장하여 추후 더블클릭이나 이동 등 레이아웃 재작업을 자유롭게 할 수 있습니다.
프로젝트 열기 & 클립보드 복사
✓ 열기 (Open) 이전에 저장해두었던 JSON 프로젝트 포맷 파일을 파싱하여 작업을 완벽히 복원합니다.
✓ 클립보드 복사 렌더링 결과를 메모리 클립보드에 스냅 복사하여 곧바로 카카오톡, 메일 등에 간편히 붙여넣기 하실 수 있습니다.
4. 조작 팁 & 핵심 노하우
• 개체 더블클릭: 캔버스 내 삽입된 텍스트, 선, 도형 등을 더블 클릭하면 각 유형에 최적화된 개체 속성 수정 창이 나타나 실시간 편집이 가능합니다.
• 반전 및 조작: 개체를 선택하면 나타나는 상단 원형 아이콘을 통해 회전, 크기 조절 뿐만 아니라 **좌우/상하 제자리 반전**이 완전한 형태로 이루어집니다.
• 다중 제어 (Shift): Shift 키를 누른 상태에서 마우스 클릭이나 드래그를 수행하면 여러 개의 요소들을 묶어서 한 번에 이동하거나 지울 수 있습니다.
• 화면 탐색 (Panning): 편집 도구가 활성화되지 않은 대기 상태에서는 빈 공간을 마우스로 드래그하면 캔버스 전체가 부드럽게 패닝 이동합니다.
💡
스크롤 캡처 활용 꿀팁
스크롤 캡처 진행 시 [Delete] 키 또는 화면 하단에 나타나는 [여기까지만 캡처] 버튼을 누르시면, 굳이 끝까지 기다리지 않더라도 현재 진행 중인 부분까지만 부드럽게 잘라서 캡처를 신속하게 마칠 수 있습니다.
