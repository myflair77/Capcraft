Capcraft 상세 가이드

각 버튼과 도구들의 상세 기능을 안내해 드립니다.

1. 캡처 도구 (Capture Tools)
📸 새캡처 버튼
직접지정: 마우스 드래그로 원하는 사각형 영역을 선택하여 즉시 캡처합니다.
창: 현재 실행 중인 특정 윈도우 창을 감지하여 해당 창 전체를 캡처합니다.
단위영역: 웹페이지나 앱 내의 개별 이미지, 버튼 등 요소 단위로 자동 영역을 잡아 캡처합니다.
전체화면: 현재 화면 전체를 즉시 캡처합니다.
스크롤: 긴 웹페이지를 자동으로 스크롤하며 고해상도 이미지 한 장으로 합쳐주는 강력한 기능입니다.
크기지정: 사전에 정의된 특정 픽셀 크기로 영역을 고정하여 캡처합니다.
2. 편집 도구 (Editing Tools)
Abc 텍스트 도구
캔버스 어디든 클릭하여 글자를 입력합니다.
하위 기능 • 글자 크기: 숫자 입력으로 크기 조절
• 스타일: B 굵게, I 기울임, U 밑줄 적용
• 색상: 글자색 및 배경색(하이라이트) 각각 지정 가능
〰️ 펜 도구
자유로운 곡선이나 직선을 긋고 형광펜 효과를 줄 수 있습니다.
하위 기능 • 펜 종류: 볼펜 (일반 선), 형광펜 (반투명 굵은 선)
• 선 스타일: 점선 선택 가능
• 긋기 방식: 일반 (자유 곡선 드래그), 줄긋기 (드래그하여 직선 긋기, 수평/수직 자석 보정)
• 속성: 선 굵기, 색상 지정 (환경설정에서 볼펜/형광펜 기본값 설정 가능)
⬜ 도형 도구
다양한 기하학적 형상을 그립니다.
하위 기능 • 도형 종류: 직사각형, 타원, 선분, 화살표 선택
• 속성: 선 굵기 조절, 선 색상 및 채우기 색상(배경) 지정
🖼️ 이미지 도구
외부 이미지 파일을 가져와 현재 작업 영역에 삽입합니다.
전용 팝업 기능 • 영역 선택: 불러온 이미지를 그대로 넣거나, 원형/사각형 등으로 잘라서 필요한 부분만 삽입할 수 있습니다.
💧 모자이크 도구
민감한 영역을 드래그하여 가려줍니다.
• 강도 조절: 1~20단계 수치 조절을 통해 픽셀화 크기를 정교하게 제어합니다.
✂️ 자르기 도구
이미지의 불필요한 부분을 잘라내어 크기를 조절합니다.
• 가변 조절: 네 변과 모서리를 드래그하여 자를 범위를 확정한 뒤 [자르기 실행] 버튼을 눌러 완료합니다.
3. 시스템 및 파일 (System & File)
💾 저장 메뉴
PNG / JPG: 고화질 이미지 형식으로 저장합니다.
PDF: 현재 캔버스를 문서 형식으로 변환하여 저장합니다.
JSON: 작업 중인 모든 개체(도형, 텍스트 등) 정보를 저장합니다. 나중에 다시 열어 위치나 내용을 수정할 수 있습니다.
📂 열기 / 복사
열기: 저장해둔 JSON 프로젝트 파일을 불러옵니다.
복사: 결과물을 클립보드에 즉시 복사하여 메신저 등에 바로 붙여넣기 할 수 있습니다.
4. 조작 팁 & 노하우
• 객체 수정: 캔버스의 개체를 더블 클릭하면 속성 수정창이 나타납니다. (내용, 크기, 색상 등 재수정 가능)
• 다중 선택: Shift를 누른 채 클릭하거나 드래그하여 여러 개체를 동시에 이동/삭제할 수 있습니다.
• 패닝 모드: 아무 도구도 선택되지 않은 상태에서 캔버스의 빈 공간을 드래그하면 화면을 자유롭게 이동할 수 있습니다.
💡 주의: 스크롤 캡처 완료 후 나타나는 [STOP] 버튼을 활용하면 긴 페이지도 원하는 지점에서 즉시 끊어 캡처할 수 있습니다.
